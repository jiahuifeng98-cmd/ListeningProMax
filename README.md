# ListeningProMax

面向中文用户的 Windows 日语精听工作台。把音频整理成逐句文稿，围绕播放、查词、翻译和收藏学习，适合日语 N1 / N2 听力练习。

[下载 Windows 分享包](https://github.com/jiahuifeng98-cmd/ListeningProMax/releases/latest) · [使用说明](docs/USER_GUIDE.md) · [开发与构建](docs/DEVELOPMENT.md) · [版本与验收范围](docs/RELEASE_NOTES.md)

![精听工作台：自编演示课程](docs/images/listening-workspace.png)

## 快速使用

1. 在 Releases 下载分享 ZIP，完整解压到可写目录。
2. 双击 `ListeningProMax.exe`。首次启动自动准备运行资源并创建桌面快捷方式，无需安装 Python 或 Node.js。
3. 导入日语音频或视频，也可一起选择 TXT / SRT / VTT，然后开始逐句精听。

压缩包包含程序、图文说明书和 20 秒宣传片。分享包约 550 MiB；首次展开运行环境和词典约需 2 GB，建议至少预留 3 GB，后续模型和课程另计。自动识别使用本地模型，首次需要按提示下载；已有音频和字幕可以直接播放学习。移动软件时，请退出后移动整个文件夹。

## 主要功能

- **逐句精听**：拖动定位、倍速、前后 10 秒、单句循环、当前句跟随及可选句首句尾缓冲。
- **文稿编辑**：纠错、合并、拆分、精确到毫秒的时间编辑、整理断句与局部重新校准。
- **查词与翻译**：本地多辞书、假名及已有音调；支持活用还原、联网查询参考和免费必应中文翻译。
- **学习管理**：课程搜索、重命名、删除；单词和句子收藏、次数排序、返回出处。
- **彩色单词**：N1—N5 与考研 203 分级，可筛选显示；社区词表来源有标注。
- **个性化界面**：明暗主题、独立日中字号、可折叠导航、自定义快捷键。正文工具集中在顶部，播放控制固定在底部。

| 默认快捷键 | 功能 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| ← / → | 上一句 / 下一句 |
| Shift 单独按下并松开 | 不循环 / 单句循环 |
| 1 | 正常听力：1×，不循环 |
| 2 | 原速精听：1×，单句循环 |
| 3 | 快速听力：1.25×，不循环 |
| 4 | 快速精听：1.25×，单句循环 |

输入框、编辑框和文字选择期间保留正常键盘行为。查词不暂停播放，译文按需显示。

## 本地优先

音频识别和时间对齐在本机运行。课程、收藏、编辑历史与运行缓存留在便携目录。开启联网翻译或点击联网查词时，仅发送相应文字；免费网页服务可能受网络、限流和接口变更影响。

仓库只包含源码、必要静态资源、脚本和许可说明，不包含制作者的课程、收藏、数据库、私人音频、模型或缓存。大型依赖和模型不进入 Git 历史，完整应用通过 Releases 分发。

## 技术与开发

Electron + React + TypeScript；SQLite 后台工作线程；Python、FFmpeg、faster-whisper、stable-ts 与 CTranslate2。耗时任务在后台执行，分段结果可续跑。

```powershell
. .\scripts\env.ps1
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm test
pnpm run build
```

以上编译源码，不自动生成完整运行时和词典。开发环境、资源准备、缓存路径与打包要求见 [开发说明](docs/DEVELOPMENT.md)。
