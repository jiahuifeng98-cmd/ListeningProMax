# 当前分享构建

应用版本：1.9.0，分享构建 `1.9.0-share.20261106`。宣传片修订：2026-11-07。

## 下载与使用

在 GitHub Releases 下载完整分享 ZIP，解压到可写目录后双击 `ListeningProMax.exe`。压缩包中包含程序、图文说明和宣传片。首次启动准备隐藏运行目录并创建桌面快捷方式，之后移动程序需移动整个文件夹。

分享包约 550 MiB，首次展开运行时和词典约需 2 GB；建议至少预留 3 GB，模型与课程空间另计。首次自动识别需要下载模型，已有音频与 SRT/VTT 可以直接精听。它不是完全自包含的离线包。

## 现有功能

- 课程导入、搜索、重命名和删除；音频/视频音轨及 TXT/SRT/VTT。
- 逐句定位、编辑、合并、拆分、循环、倍速和自定义快捷键。
- 四种听力模式，数字键 1—4 快速切换；播放器固定在底部。
- 顶部集中工具，彩色词汇筛选位于二级面板。
- 本地辞书、假名和已有音调；免费必应联网翻译与查询参考。
- 单词/句子收藏、次数排序、词汇等级和返回原句。
