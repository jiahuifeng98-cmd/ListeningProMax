# ListeningProMax 1.9

Windows 本地日语精听工作台。当前个人完整版保留已有模型；轻量分享版内置播放器与词典，识别模型按需下载。音频在本机处理。

## 启动

1. 本机运行 `release/ListeningProMax/ListeningProMax.exe`；分享给别人请发送最新发行 ZIP，避免带上个人课程和收藏。
2. 双击目录最外层的 **ListeningProMax.exe**。无需安装 Python、Node。轻量分享版自动识别前需要按提示下载模型；已有音频和 SRT/VTT 可直接精听。
3. 首次启动会建立课程数据库和本地词典索引副本。不要单独移动 EXE；退出后移动整个文件夹即可。

当前交付为功能验收版。1.9 可选循环间隔、边界缓冲、焦点和异常识别修复见 `ACCEPTANCE-v1.9.md`。1.8 播放缓冲、课程删除、自动补译与平滑切句见 `ACCEPTANCE-v1.8.md`。1.7 全套界面和图标重设计见 `ACCEPTANCE-v1.7.md`。1.6 视觉与快捷键更新见 `ACCEPTANCE-v1.6.md`。1.5 编辑、查词和交互更新见 `ACCEPTANCE-v1.5.md`。联网翻译更新见 `ACCEPTANCE-v1.4.md`，N1/N2 对话断句见 `ACCEPTANCE-v1.3.md`，播放性能见 `ACCEPTANCE-v1.2.md`。`ACCEPTANCE.md` 是 1.0 历史报告，不代表全部质量门槛已通过。

## 导入与精听

- 精听上方的「彩色单词」可开关配色，展开后逐项勾选要标注的等级；选择会自动保存。N1 黄、N2 红、N3 绿、N4 蓝、N5 亮紫、考研黑，其余灰。多重归属取最低等级（N5 → N4 → N3 → N2 → 考研 → N1）；未勾选的等级变灰，不改用其他归属的颜色。关闭模式恢复原有字色。深色模式考研黑字配浅色底。
- 彩色标注复用本地分词器识别基本活用形，不联网、不下载新模型，不改写句子及时间轴；查词和播放照常使用。收藏页显示词汇等级，悬停标签可看其他归属。「未分级」仅表示当前词表未匹配，不代表超纲。社区词表、203 核心词汇笔记来源与许可见 [词表来源说明](../licenses/vocabulary-sources.md)，验证见 [实测报告](RELEASE_NOTES.md)。

- 点击「导入素材」，或把文件拖进窗口。同一次导入选择一段音频/视频及其 TXT、SRT 或 VTT。只有文本也能阅读、查词和收藏，稍后关联音频。
- 只有音频时，后台执行提取音轨、识别、补标点和逐句对齐。音轨准备好后即可播放；视频只播放音轨。
- TXT 的文字保留，整理仅允许标点和换行变化；无法匹配的文字保留，没有时间的位置显示「等待对齐」。SRT/VTT 初次保留字幕时间；需要时点「重新校准」。已取消「需复核／待校准」徽标和顶部计数，具体处理失败仍显示在任务栏和日志。
- 点击句子定位；拖动底部进度条立即跳转。空格播放/暂停，左右方向键切句，单独按下并松开 Shift 切换循环（输入、选择文字或组合键时不触发），按钮前后 10 秒，菜单选择倍速。不绑定 Alt/Ctrl 快捷键。输入框中按键正常编辑。
- 循环按钮只在不循环、单句循环两种模式间切换。单句循环中仍可切句或拖动，循环目标随之更新。
- 右上角「原文显示/隐藏」为两态切换。隐藏仍保留句位和播放标志。

## 1.8 使用变化

- 中文译文显示时，保存修改、合并或拆分后自动补译；后台拆分成功后开始，失败重试仍有效。

## 修订和收藏

- 「整理断句」使用已有词级时间，根据日语词形、句尾和停顿重组正文，不重新识别整课。旧版在处理窗口末尾补出的句号会重新判断，避免把「取り組んで」截成两段；天然标点、文字顺序、手工时间锚点保留。缺少可靠词级时间或文字与时间不匹配的片段保持原样，可先校准再整理。处理在后台完成，成功后替换，失败保留原稿。
- 新导入的音频自动执行这一断句步骤。整理只会沿用既有绝对词界，不用句长比例估算时间，因此不会添加累计偏移；已有词界不准仍须重新校准或手改。改句导致原译文不再对应时，仅相关译文失效。
- 1.3 默认加入面向 N1/N2 对话的口语规则：处理「んだって」「よね」「だな」「んだ」及短应答；保护引用、间接疑问、选择结构和句中语气词，如「するかしないか」「今ね」。不需要另开模式。已有课程点一次「整理断句」；本次已整理 2017 年 12 月 N2 课程。重复整理同一结果不会继续拆碎。
- 旧版「思。／うけど」等跨词断点会在词形证据充分时修复。新版记录自动句号来源，手工编辑的句末受到保护。真实对话的中断或省略会保留原话，不补造缺失内容；识别错字、说话人归属及没有可靠词界的段落不能仅靠这一步保证正确。
- 句子右侧铅笔可纠错及修改 `00:01:23.450` 格式的起止时间。手改时间固定为锚点，后台重新对齐后续内容至下一锚点。对齐失败保留现有时间轴，并保留候选结果供排查。
- 只改文字保留句级时间，不自动启动校准；旧译文与失效的词级边界清除。合并按钮保留两句全部文字；编辑框可在光标处拆分。有词级边界时直接拆分，否则局部对齐成功后一次性提交；失败保留原句，不产生无法播放的半成品。已取消撤销和重置时间轴功能，历史数据仍保留。
- 1.5 已移除参考资料功能。旧参考原文和历史保留在数据库与课程备份内；旧收藏保留参考摘录。整理断句、重新校准集中在右上角。左上角常驻「返回当前句」，仅滚动定位，不跳转播放时间或改变暂停状态。
- 在正文选中词语即弹词卡。三栏对照，中文主释义突出，显示假名及已有音调；无数据明确显示缺失。联网结果在上部蓝色区域用 24 px 文字显示，假名在标题旁单独显示。数字助数词和金额如“3週間”“1万円”“10,000円”可离线补充读音，标明规则来源；未覆盖或有歧义的词不猜测。关闭或 Esc 清除选区，不暂停播放。
- 收藏单词按词形和读音去重，并保留不同出处。收藏句子按身份去重；在「我的收藏」返回原句；原参考资料收藏显示保留的摘录。


## 当前交互说明

- 正常播放时当前句居中；首尾句也能居中。选词、编辑、手动浏览时暂缓；浏览结束 3 秒后恢复播放跟随，也可点左上角常驻的“返回当前句”。暂停时不抢滚动位置。
- 1.7 默认日语 28 px、中文 17 px，当前句以浅蓝底色和适中字重区分；显示译文不会缩小日语。设置可分别选择日语 24–36 px、中文 14–22 px。左上角可将导航收起为 64 px 图标栏，状态自动保存。
- 失败或取消任务可点 × 关闭提示，重启后保持关闭，设置页仍可查看详情和重试。重试采用新任务及当前编辑版本，原文和成功缓存保留。
- 查词支持多步活用还原，例如“使われて”→“使う”；显示原形读音与可取得的词形读音，形态分析读音注明来源，音调不猜测。
- 词卡上部“联网查询”仅手动发送所选词形至必应，不上传整篇课程，返回内容标为“中文翻译参考”，不冒充辞书释义，不生成音调。最多等待 10 秒，可取消；网络不可用时本地结果继续使用。

## 中文翻译

首次点击右上角「中文翻译」才按设置启动翻译，译文插入各句下方。任务栏显示实际批次进度，可取消和继续；已有译文会缓存，改正文只使该句译文失效。

设置中勾选「启用免费联网翻译」并保存，使用 **微软必应（日语 → 简体中文）**，无需密钥、账号或付费接口。已移除 Google 和 MyMemory 选项，旧设置自动迁移到必应，原有联网开关、本地回退偏好及已保存译文保留。只发送待翻译的句子，音频留在本机；最多 3 个请求并发，相同句子去重，完成即保存。网络不可用或限流时，可自动回退本地模型；也可以关闭回退，仅重试未完成部分。

必应使用中文网页入口，跟随其在 `cn.bing.com` / `www.bing.com` 之间的正常跳转；本机禁用 HTTP 代理的日中翻译实测通过。使用的是免费网页服务，接口变更、限流或需要人工验证时会报错或回退本地，不无限重试，也不将错误页面保存成译文。没有接入 Azure 付费订阅接口。各地运营商网络仍可能不同。

## 保存、恢复与任务排查

课程自动保存到 `data/library.sqlite`。右上角导出 TXT/SRT/VTT，或导出包含媒体、参考资料、译文与收藏出处的课程备份 ZIP。通过「导入素材」选中单个备份 ZIP 可恢复为新课程。未对齐句子不会被编造时间导入字幕；完整正文可导出 TXT。

处理中退出、取消或异常退出后，可在设置的任务列表「继续 / 重试」。识别/对齐结果按音源及模型保存在 `data/analysis`，跨任务复用；改音源、模型或有关文字会使对应缓存失效。任务日志和候选稿在 `data/jobs/<任务ID>`。不要删除这两处续跑资料。日志包括 `worker.log`、`inference.log`，未识别区间在 `failed-regions.json`。失败不会无限等待或静默改用小模型。

支持直接播放的音频复用导入的原文件，视频提取无损 FLAC；另保留 16 kHz 分析 WAV（两小时约 230 MB）。不再生成大体积的立体声播放 WAV。备份仍需额外空间。任务或导出报空间不足时，先释放本磁盘空间再重试。

面向 Windows 10/11 x64、8 GB 内存、SSD、普通四核 CPU。当前推理固定走 CPU，标准模型为 large-v3-turbo INT8 计算，省资源模式为 small INT8；不会静默降级。安装包包含全部模型，因此磁盘体积不等于日常播放内存占用。

请从外层启动器进入，应用及子进程主动生成的课程、缓存和临时文件均定向到便携目录；目录不可写就报错。Windows 本身的日志、分页和安全软件活动不在应用控制范围内。完整系统文件写入追踪尚未验收，详见验收报告。

## 从源码构建

源码位于同一项目根目录。开发需 Node、pnpm；运行便携成品不需要这些工具。

若只拿到了源码 ZIP，先将完整便携包中的 `runtime`、`models`、`assets` 复制到源码根目录，再执行下列命令。这样构建无需重新下载模型，也不依赖原开发电脑的路径。

```powershell
. .\scripts\env.ps1
pnpm install --frozen-lockfile
node node_modules\typescript\bin\tsc --noEmit
node node_modules\vitest\vitest.mjs run
node scripts\build.mjs
node scripts\check-storage.mjs
node scripts\smoke.mjs
node scripts\package.mjs
.\runtime\python\python.exe scripts\archive.py
```

`env.ps1` 先设置本项目的缓存、临时文件和模型路径。已下载资源由 `assets/manifest.json` 固定来源、revision 和 SHA-256；`scripts/restore-assets.py` 按清单恢复。Python 依赖版本见 `requirements.lock.txt`，JS 精确版本见 `pnpm-lock.yaml`。`scripts/package.mjs` 需要 Windows 自带 .NET Framework 的 C# 编译器生成便携启动器。

按需运行 ZIP 打包脚本时，会生成 `SHA256SUMS.json` 成品文件校验清单。本次更新的代码逐文件核对记录在项目 `reports/v11/delivery.json`。测试素材、开发缓存、私人课程和密钥均不纳入发布 ZIP。


## 1.1 文稿处理与空间管理

保留标准识别与 stable-ts 强制对齐；不再整篇送 Qwen 改写已经有标点的 ASR 文稿。使用既有词级时间、日语词形及口语句尾整理断句，诊断留在后台，不承诺语义断句一定正确。参考资料整理使用保守换行拼接，逐字校验，不改词、不翻译。识别完成即先显示初稿，对齐在后台继续；取消/失败保留已完成步骤。空文稿点击生成会走识别流程，不能把空结果标成校准成功。

本次取消 Qwen 模型及其运行时，并清理旧验收副本、旧 ZIP 和可重建下载缓存。`scripts/cleanup-project.ps1` 默认只预览固定清单，带 `-Apply` 才清理。课程数据库、收藏、媒体源文件、分析续跑缓存不在清理清单中。开发目录与便携目录的相同不可变资源可通过 `scripts/deduplicate-resources.py` 去重；便携目录自身仍完整可复制。后续修改先验证新版本，再清理旧产物，不在项目里累积多套安装目录与 ZIP。
